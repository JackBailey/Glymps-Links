# Glymps Website


A HTML, CSS + JS Website to show my top played games, jump between social sites and work with my [YOURLS](https://jackb.link) installation using a prefix of glymps/


### LanyardAPI

This site makes use of Phineas' brilliant [Lanyard API](https://github.com/Phineas/Lanyard) to provide information about my Discord Account, which I use to update my status at the top, as well as update the logo and username + #discordtag at the top.

### Glymps API

A simple API Wrapper used to fetch my top 100 most played games as well as get information such as Name, Link, Image and Playtime returned in a variable amount. Example: https://api.glymps.xyz/top25games will print out the top 25 games from most played to least. The 25 can be anything less than 100, if it isn't included it will return 10.

<sub>[Source Code](https://repl.it/@jackbailey/glympsapi)</sub>
